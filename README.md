# PSM Program Scorecard — Claude Code Skill Demo

A walkthrough demo of the **PSM Program Scorecard** skill for [Claude Code](https://claude.ai/claude-code) — an AI-powered skill that pulls live delivery data, scores enablement programs, analyzes survey comments, and publishes a formatted scorecard directly to Slack, all in a single guided conversation.

---

## What It Does

The PSM Program Scorecard skill automates the end-to-end process of building a quarterly enablement program scorecard:

1. **Pulls live data** from the Tableau Live Delivery Dashboard via REST API
2. **Fetches survey comments** from the Readiness Salesforce org via SOQL
3. **Scores programs** using the Combined Enablement Menu Health Framework (CSAT, Attendance, Reach, Adoption)
4. **Assesses impact** using OPM+ ramp milestone data provided by the PSM
5. **Analyzes learner feedback** and surfaces themes, standout quotes, and recommended actions
6. **Publishes a formatted Slack Canvas** to the PSM's DM or a specified channel

A scorecard that previously took hours of manual data pulls, spreadsheet work, and write-up now takes a single conversation.

## How to Use the Skill

### Prerequisites

- [Claude Code](https://claude.ai/claude-code) desktop app (Mac or Windows)
- Tableau personal access token configured in `~/.claude/settings.json`
- Salesforce CLI (`sf`) installed and connected to the Readiness org (`sf org login web --alias readiness --instance-url https://readiness.my.salesforce.com`)
- Slack MCP connector connected in Claude Code Settings → Connectors

### Running the Skill

In any Claude Code session, type:

```
/psm-scorecard
```

Claude will run a pre-flight check (Slack, Tableau, Readiness), then ask for:

1. Your name
2. Program name(s) — fuzzy-matched to the dashboard
3. OPM+ impact data (pasted from the dashboard)
4. Scorecard destination (your DM or a channel)

The rest is automated.

## What the Skill Produces

Each scorecard includes:

| Section | Contents |
|---|---|
| **At a Glance** | Quality flag (🟢 🟡 🔴), Quadrant, NBA, Impact call, key metrics |
| **Reach & Engagement** | Unique learners, enrollment, attendance, class size, sessions |
| **Experience & Quality** | CSAT, Facilitator Score, Content Effectiveness vs. goals |
| **OPM+ Impact** | YoY milestone table, impact call (HIGH / LOW / Not Available) |
| **Trend** | 4-quarter trend table with directional indicators |
| **What's Going Really Well** | 5–7 themes with representative learner quotes |
| **Themes & Opportunities** | 5–7 actionable improvement themes with quotes and recommendations |
| **Top 3 Recommended Actions** | Prioritized, specific next steps |
| **Notes & Caveats** | Data flags, quarter-in-progress notes, source provenance |

## Scoring Framework

| Metric | Goal |
|---|---|
| CSAT | ≥ 4.6 |
| Facilitator Score | ≥ 4.6 |
| Content Effectiveness | ≥ 4.6 |
| Attendance Rate | ≥ 70% |
| Reach % | ≥ 50% |

**Quality Flags:** 🟢 Healthy · 🟡 Caution · 🔴 At Risk

**Quadrants:** ⭐ Core Driver · 👥 Crowd Pleaser · 💎 Hidden Gem · 🌙 Sunset

## Data Sources

| Source | What It Provides | Access Path |
|---|---|---|
| Tableau Live Delivery Dashboard | All delivery metrics (CSAT, attendance, reach, enrollment, class counts) | REST API v3.19 with personal access token |
| Readiness Salesforce Org | Full survey comment text, filtered by program and quarter | Salesforce CLI (`sf data query`) |
| OPM+ Dashboard | YoY ramp milestone data by role | PSM-supplied (API returns top-level KPI only) |
